# 💜 Emotion Cipher - Hackathon Edition

**Theme:** AI + NLP + Encryption Logic  
**Project:** Emotion-Aware Encryption  

---

## 📝 Overview
Emotion Cipher is a web-based app that **encrypts text messages** while still **detecting the underlying emotion**.  
It balances:  
- **Privacy**: Original text stays secure  
- **Empathy**: AI can detect emotion even from encrypted messages  

---

## 🚀 Features
- Encrypt text messages securely 🔐  
- Detect emotions in text (Joy, Sadness, Anger, Excitement…) 🤖  
- Decrypt messages back to original text  
- Animated AI brain reacting to emotion 💫  
- Floating emojis representing emotion intensity  
- Glowing, hoverable emotion badges ✨
